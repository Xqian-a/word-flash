# 速记 Word Flash

黑白配色的英语单词速记工具，支持批量导入、快速标记、释义查询。

## 功能

- **批量导入** — 粘贴文本或上传文件（支持 CSV/TXT），自动解析单词和释义
- **速记模式** — 每页 20 个单词铺满屏幕，左键标记认识，右键翻转查看释义
- **分类管理** — 认识/不熟两个分类，支持从不熟中继续速记
- **中文释义** — 内置四级核心 1500 词中文词典，其他词自动翻译
- **导出单词本** — 支持正常单词本、默写本、自测本三种格式（CSV/TXT）
- **顺序/随机** — 可按词汇表顺序或打乱随机背诵
- **数据备份** — 导出/导入 JSON 数据，跨设备同步学习进度

## 使用

直接打开 `index.html` 即可使用，无需服务器。

或访问 [GitHub Pages 在线版](https://your-username.github.io/word-flash/)。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 主应用 |
| `dict_data.js` | 内置四级中文词典数据 |
| `cet4_core_words.txt` | 四级核心 1500 词（可上传导入） |

## 词表格式

支持以下格式导入：

```
# 每行一个单词
abandon
ubiquitous

# 单词 + 释义（Tab 分隔）
peril	n. 严重危险
confess	v. 承认；坦白

# PDF 原文格式
1. peril [ˈperəl] n. 严重危险
2. confess [kənˈfes] v. 承认；坦白
```
